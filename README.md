# Контур

Интерактивная логическая задача с двумя системами скрытых связей.

## Локальный запуск

Откройте `dist/index.html` в браузере. Сборка и зависимости не требуются.

## GitHub Pages

После отправки репозитория на GitHub откройте **Settings → Pages** и выберите
**Source: GitHub Actions**. Workflow автоматически опубликует содержимое `dist`.
